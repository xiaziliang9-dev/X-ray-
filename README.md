# X-ray 审图百宝箱

内部质检审图用的浏览器扩展（Edge / Chrome）。把审图、复核里的重复操作收进一个面板，减少来回点。

> 只在公司内网审图系统页面生效，不采集、不上传任何数据。

**当前版本 v1.4.61** · 更新于 2026-10-27

[⬇ 下载最新版](https://github.com/xiaziliang9-dev/X-ray-/releases/latest/download/xray-extension.zip)

---

## 一、安装（第一次，只做一次）

1. **下载**上面的最新包（`xray-extension.zip`）
2. **解压**到一个固定目录，例如 `D:\Tools\Xray审图助手`
   > 别放桌面或下载文件夹 —— 那里容易被清理，删掉扩展就失效了
3. 浏览器打开扩展管理页
   - Edge：地址栏输入 `edge://extensions`
   - Chrome：`chrome://extensions`
4. 打开右上角 **开发人员模式**
5. 点 **加载解压缩的扩展**，选择第 2 步解压出来的文件夹
   > ⚠️ 要选到**能看到 `manifest.json` 的那一层**，选外层会提示"清单文件缺失"
6. 打开审图系统页面，右下角出现统计悬浮窗就装好了

## 二、更新（以后有新版本）

### 方式一：扩展里点一下（推荐）

审图页面 → 扩展图标 → **⚙ 设置** → 左侧「版本更新」

1. 点 **检查更新**
2. 有新版本就点 **立即更新（下载新版）**
3. 下载后解压，覆盖第 2 步那个文件夹
4. 回扩展管理页点 **↻ 重新加载**，再刷新审图页面

### 方式二：直接下包

下载最新 zip → 解压覆盖 → 扩展管理页点 **↻** → 刷新审图页面

> **整个过程不需要任何本机程序**，也不用先打开什么工具。
> 上面的下载链接永远指向最新版，可以存进收藏夹。

## 三、功能

| 模块 | 用途 |
|---|---|
| 图像调节 | 8 项光影调节、像素测量、预设方案 |
| 文本规则 | 高亮 / 禁用 / 互斥 / 替换 / 提交按钮，设置页统一调整 |
| 实时统计悬浮窗 | 实时榜 / 周榜 / 导出表格 |
| 算法框配色 | 按大类自动配色、悬停高亮 |
| X光图对比 | 双图联动缩放、切图层 |
| 自动化生产 | 连点器 + 翻图自检 |
| 模板复制 | 提问工艺 / 质检信息 / 审图群，三个模板可改、可单独开关 |

所有快捷键在 **设置 → 快捷键** 统一修改，自动检测冲突。

## 四、云端配置（仓库里的两个 json）

| 文件 | 用途 |
|---|---|
| `xray-config.json` | 文本规则 + 三个复制模板的内容。设置页「云端更新」拉取 |
| `update.json` | 版本清单。检查更新时读，GitHub 接口被限流时靠它兜底 |

**维护者改完规则 / 模板**：更新 json 里的 `version`（+1）和 `note`（写这次改了什么）→ 提交。
同事下次点「检查云端」，卡片上就会显示「本次更新：…」。

## 七、常见问题

**装完没反应 / 悬浮窗不出现**
- 确认当前页面是审图系统（扩展只在那几个域名生效）
- 扩展管理页确认扩展状态是「已启用」
- 刷新页面（F5）

**更新后功能没变化**
- 覆盖完必须回扩展管理页点 **↻**，再刷新审图页面。少这一步就还是旧版本在跑

**检查更新提示失败**
- 换网络 / 关掉代理再试
- 或者直接用页面顶部的下载链接

**能自动升级吗？**
- 不能。浏览器不允许扩展自己静默升级，必须「下载 → 覆盖 → 重载」三步
